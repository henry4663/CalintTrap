# Goblox

## Download para Windows

[**Baixar Goblox para Windows**](https://github.com/henry4663/CalintTrap/actions/workflows/build-windows.yml)

1. Abra o link acima e selecione o build mais recente com status **Success** (verde).
2. Na página do build, desça até **Artifacts**.
3. Baixe `Goblox-Windows.zip` e extraia o arquivo.
4. Execute o instalador `.exe`.

> O instalador é disponibilizado nos Artifacts do GitHub Actions. Builds podem expirar após 14 dias.
